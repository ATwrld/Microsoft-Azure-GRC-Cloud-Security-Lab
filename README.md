I designed and configured a simulated Microsoft Azure cloud environment for a fictional financial services organization. I implemented identity and access management, network security, storage protection, activity logging, and Microsoft Sentinel monitoring.

I conducted a risk assessment, mapped security controls to NIST CSF 2.0, documented supporting evidence, and developed remediation plans for identified security gaps.

This project strengthened my practical skills in Azure security, cloud governance, risk assessment, compliance documentation, and security monitoring.
